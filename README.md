# glottohotspot

We identify global hotspot regions where high linguistic diversity values are significantly clustered. We map these hotspots for richness and endemism for languages, genealogies and structural features, and assess their spatial congruence. 

Citation: Norder, Sietze and van Gijn, Rik. "Global hotspots of linguistic diversity: mapping richness and endemism" Linguistic Typology, 2026. https://doi.org/10.1515/lingty-2024-0053
